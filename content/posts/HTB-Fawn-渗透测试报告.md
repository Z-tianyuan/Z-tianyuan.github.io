### 二、渗透测试完整流程

#### 阶段 1：信息收集（端口扫描）

```bash
nmap -sV -T4 -Pn 10.129.136.100
```

**扫描结果：**

```
PORT   STATE  SERVICE    VERSION
21/tcp open   tcpwrapped
```

**关键发现：** 目标开放 21 端口，即 FTP 服务。"tcpwrapped" 说明 nmap 无法识读版本号，但端口号本身就是最强指纹——21 = FTP。

---

#### 阶段 2：漏洞分析

FTP（文件传输协议）常见攻击面：

1. **匿名登录** — `anonymous` 账户无需密码直接登录（最可能）
2. **弱密码爆破** — 使用 hydra 对常见用户名/密码字典进行尝试
3. **FTP 版本 CVE** — 特定版本存在远程代码执行漏洞（如 vsftpd 2.3.4 后门）
4. **敏感文件泄露** — 登录后可读取的配置文件、数据库备份等

入门靶机大概率是匿名登录。

---

#### 阶段 3：漏洞利用

```bash
ftp 10.129.136.100
```

连接后提示输入用户名和密码：

```
Name (10.129.136.100): anonymous
Password: (直接回车，空密码)
```

**结果：** 230 Login successful，成功以匿名身份登录。

---

#### 阶段 4：Flag 获取

FTP 与 Telnet 不同——文件需要通过 `get` 命令下载到本地，而非直接在终端查看：

```bash
ls              # 列出远程文件
get flag.txt    # 下载 flag 到本地
bye             # 退出 FTP
```

退出后 flag.txt 已保存在本地当前目录，直接打开即可。

**常用 FTP 命令速查：**

| 命令 | 作用 |
|------|------|
| `ls` | 列出远程文件 |
| `get <file>` | 下载单个文件 |
| `mget *` | 批量下载所有文件 |
| `cd <dir>` | 切换远程目录 |
| `bye` | 退出 FTP 会话 |
| `binary` | 切换为二进制传输模式（下载图片/程序必须） |

### 三、两机对比：Meow vs Fawn

| | Meow | Fawn |
|------|------|------|
| 端口 | 23 (Telnet) | 21 (FTP) |
| 攻击方式 | 空密码 root 登录 | anonymous 匿名登录 |
| 交互模式 | 持续命令行会话 | 文件传输模式 |
| 获取 flag | `cat flag.txt` | `get flag.txt` |
| 核心教训 | Telnet 不安全+弱密码 | FTP 匿名访问未关闭 |

**共同的思维链：** 扫描 → 识别服务 → 针对服务类型尝试常见弱点 → 获得访问 → 拿 flag。

---

### 四、修复建议

| 问题 | 建议 |
|------|------|
| FTP 匿名登录 | 禁用 anonymous 账户 |
| FTP 明文传输 | 替换为 SFTP 或 FTPS，加密数据传输 |
| 无访问控制 | 配置防火墙白名单，限制 FTP 访问来源 |
| 敏感文件可读 | 限制 FTP 用户目录范围（chroot），不允许遍历系统文件 |

---

### 五、拓展思考

**匿名 FTP 在真实渗透中的价值：**

如果在真实目标的公网 FTP 碰到匿名登录，不只是拿 flag，还可以：

1. **情报收集** — 查看共享的文件，获取用户名、内部文档、网络拓扑
2. **上传 Webshell** — 如果 FTP 目录恰好是 Web 根目录，上传一句话木马拿 WebShell
3. **内网跳板** — FTP 服务器往往同时连接内外网，可作为横向移动的起点
4. **密码喷洒** — 发现的用户名列表可用于其他服务（SSH、邮箱）的密码爆破
