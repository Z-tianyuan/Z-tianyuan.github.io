    🎯 本周核心目标#

    从"会写代码"升级到"懂架构"，完成大厂 SOC 架构师级别的思维跃迁。同时打磨简历项目描述，准备面试话术。

    📚 模块一：大厂高阶架构思维#

    快慢车道 (Fast/Slow Path) 设计#

    • 核心概念：轻量随机森林审查 100% 流量（快车道），只把"看似正常"的流量送入昂贵 LSTM（慢车道）做时序深度分析。
    • 解决的问题：算力与精度的博弈——LSTM 极耗 GPU，不能对每个包都跑一遍。
    • 关键认知：如果第一层直接放行，第二层根本看不到它。所以是"判黑立即拦截，判白送入慢车道观察"。

    采算分离架构#

    • 核心概念：底层 C++/eBPF 探针抓包 → Kafka 消息队列削峰填谷 → Python AI 消费层。
    • 踩坑记录：面试官指出 Python Scapy 面对 10Gbps 骨干网时连"看"都看不过来，网卡缓冲区会瞬间爆满。随机抽样救不了抓包层，必须从架构层面分离采集和计算。

    SOAR 自动化防御闭环#

    • 核心概念：AI 判定拦截后，通过 requests 调用 WAF/Nginx API 实时下发封禁 IP。
    • 防反噬机制：TTL 动态解封——首次封 15 分钟，换端口再来封 2 小时，避免误杀整个 NAT 出口（如星巴克场景）。

    🔁 模块二：面试模拟与查漏补缺#

    SOC 架构师三大拷问#

    考题 核心考察点 掌握程度
    沉默的报警器 OOD 问题——模型对未见过的攻击标记为 BENIGN ⭐⭐⭐⭐
    业务部门投诉 类别不平衡 + Precision/Recall 权衡解释 ⭐⭐⭐⭐
    诡异的"预知未来" 时序数据不能用 train_test_split 随机打乱 ⭐⭐⭐⭐⭐

    时序数据致命陷阱（深度理解）#

    • train_test_split 会随机打乱时间顺序，导致模型用"未来"数据预测"过去"。
    • 训练集 99.9% 准确率是假的——生产环境中因果逻辑被破坏，模型彻底失效。
    • 正确做法：按时间顺序切分（前 80% 训练，后 20% 测试）。
